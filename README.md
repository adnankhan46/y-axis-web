# Y-Axis

**Navigate through long LLM chats.**

A time-saving sidebar for ChatGPT, Gemini, and Claude. Jump to any part of your conversation instantly.

![Y-Axis Sidebar Preview](/assets/sidebar-1.png)

## Overview

Y-Axis is a browser extension that helps you navigate through long AI/LLM chats with ease. It automatically generates a timeline of your conversation, allowing you to jump back and forth instantly.

- **Contextual Sidebar**: Automatically generates a timeline of your conversation.
- **Privacy First**: Runs entirely in your browser. No data sent to external servers.
- **Open Source**: Built in the open, for everyone.
